隐私政策

最近更新：2026-11-19

本页是英文版的中文译本；如有不一致，以英文版为准。

Nearvale 是一款在 Apple Watch 离开时锁定 Mac 的菜单栏应用，设计上不需要知道任何关于你的信息。本政策说明数据离开你 Mac 的少数几种情况，以及你购买许可证或访问本网站时会发生什么。「我们」指许可协议中写明的 Nearvale 开发者。

摘要

  • 距离检测、锁屏和全部设置都只在你的 Mac 上。
  • 免费试用期间不发起任何网络请求。
  • 购买后，应用只在激活、重新校验和停用许可证时联系 Dodo Payments，发送许可证密钥与一个随机设备标签。
  • 没有埋点、追踪、广告或崩溃上报；我们从不接收你的密码。

只留在你 Mac 上的数据

  • 蓝牙信号读数：来自你的手表（以及你选择的辅助设备），用来判断你是否在附近。它们只在内存中处理；只有每次锁定那一刻的信号强度会保存在锁定记录里。
  • 设置、锁定记录（每次锁定的时间、原因与信号强度，最多 200 条）与诊断日志（锁定、进出信任场所、所绑定设备名称等事件），保存在你的用户资源库中。你可以在「设置 → 诊断」里导出或清空。
  • 授权状态，以及仅在你开启可选的「托管密码自动输入」时的登录密码，保存在 macOS 钥匙串中。
  • 位置是可选的。授权定位服务后，Nearvale 会读取 Wi-Fi 名称；只有你保存了按位置的信任场所，才会把当前位置与之比对。位置只在本机比对，从不上传。

应用发起的网络连接

  1. 许可证激活与校验（仅付费版本）：激活时、此后约每 7 天、以及停用时，应用通过 HTTPS 向 Dodo Payments 发送你的许可证密钥和一个随机设备标签（例如「Mac-1A2B3C」），不发送电脑名称或任何使用数据。
  2. 检查更新：只在你点击时向 GitHub 发送一次请求，读取最新版本号，不带任何本机信息。
  3. 地图图块：只在「在地图上选择…」窗口打开期间，由 Apple 地图加载当前画面的图块；你选的位置不会被发送。

和所有网络请求一样，这些连接会让对方服务（Dodo Payments、GitHub 或 Apple）看到你的 IP 地址，适用其各自的隐私政策。

购买时

购买由记录商户 Dodo Payments 处理。Dodo Payments 会收集你的姓名、邮箱、账单国家 / 地区和支付信息，用于完成付款、计算税费、防范欺诈和发送许可证密钥，适用 Dodo Payments 隐私政策。我们会收到邮箱、国家 / 地区、金额和许可证密钥等订单信息，用于提供许可证、退款与支持；我们不会收到完整的银行卡信息。

本网站

本网站是托管在 GitHub Pages 上的静态网站，不使用 Cookie、分析工具或第三方脚本。GitHub 可能保留 IP 地址等常规服务器日志，适用 GitHub 隐私声明。购买完成后，Dodo Payments 可能把你带回我们的感谢页，并在网址里附上许可证密钥；页面会把密钥显示给你、从地址栏中移除，并且不会发送到任何地方。

邮件

如果你发邮件到 support@nearvale.app，我们只用你的邮件和地址来回复并帮助你。你附上的诊断日志已由应用脱敏。

保存期限与你的权利

订单记录在提供许可证所需的期间内、以及税务和会计法规要求的期限内保存；支持邮件在帮助你所需的期间内保存。你可以随时要求查阅、更正或删除我们持有的你的个人信息；法律要求保留的部分订单记录除外。你 Mac 上的数据由你掌控：删除应用及其数据即可清除。

儿童

Nearvale 不面向 14 岁以下的儿童，我们也不会有意收集他们的个人信息。

变更

本政策如有变更，我们会更新上方日期。重大变更（例如新增一种网络连接）也会写进引入它的那个版本的发布说明。
