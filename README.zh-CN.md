# Nearvale

[English](README.md) · 简体中文

**人一走，Mac 自动锁屏。**

Nearvale 是一款 macOS 菜单栏应用：Apple Watch 走远时自动锁定 Mac，回来时点亮屏幕。手表上不用装任何东西，不需要账号，没有任何统计。

![Nearvale 示意动图：手表走远、Mac 锁屏、回来后屏幕点亮](https://nearvale.app/assets/demo-zh.gif)

*工作方式的示意图，不是屏幕录制。*

## 功能

- **走开就锁，回来就亮。** 使用 Apple Watch 本来就在发的蓝牙信号。
- **按你的工位校准。** 十秒校准向导，按你的房间、Mac 和手表生成阈值。
- **从误锁中学习。** 标记一次误锁，阈值会自动放宽。
- **不碍事。** 信任场所（按网络或地图上的位置）、通话或演示期间暂缓锁定、手表偶尔掉线时可用 iPhone 等辅助设备兜底。
- **隐私优先。** 试用期间完全不联网；购买后只向支付服务商联网做许可证激活与复查。没有统计，没有崩溃上报，从不存储或发送你的密码。
